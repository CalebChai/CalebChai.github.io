机器人路径规划项目 Robot Path Planning Project

基于 RRT 算法的小型 AGV 路径规划研究 Small AGV Path Planning Based on RRT Algorithms

Course Project | Zhejiang University | 2024 Course Project | Zhejiang University | 2024
AGV Path Planning RRT RRT* RRT-Connect Dynamic Obstacle Avoidance Robot Navigation

本项目使用小型足球机器人模拟物流自动化场景中的 AGV 路径规划问题， 研究基于 RRT 的路径规划方法在复杂障碍物环境下的自主导航和避障效果。 实验模拟二维仓储环境，并考虑随机障碍物、多 AGV 路径干涉和动态避碰问题。

This project used a small-size soccer robot to simulate AGV path planning in logistics automation scenarios. It studied RRT-based path planning for autonomous navigation and obstacle avoidance in complex environments, including randomly distributed obstacles, multi-AGV path interference, and dynamic collision avoidance.

  • 构建 5m × 10m 二维仓储环境，模拟货架、堆叠物等障碍物分布。
  • 实现并对比 RRT、RRT* 和 RRT-Connect 等路径规划方法。
  • 使用双向 RRT 思路，从起点和终点同时扩展搜索树，提高路径搜索效率。
  • 设计路径干涉检测机制，在多个 AGV 路径相交时进行避让与重新规划。
  • 实验结果显示算法能够在复杂障碍物环境中完成避障，并具备较好的实时性。
  • Built a 5m × 10m two-dimensional warehouse-like environment with simulated shelves and obstacles.
  • Implemented and compared RRT, RRT*, and RRT-Connect path planning methods.
  • Applied a bidirectional RRT strategy by expanding search trees from both the start and target positions.
  • Designed path interference detection for multi-AGV scenarios and triggered avoidance or replanning when needed.
  • Experimental results showed effective obstacle avoidance and good real-time performance in complex environments.

该项目展示了机器人路径规划、动态避障和多机器人路径干涉处理能力。

This project demonstrates robot path planning, dynamic obstacle avoidance, and multi-robot path interference handling.

嵌入式 IoT 项目 Embedded IoT Project

智能家居的智能联动与数据分析平台 Smart Home Intelligent Linkage and Data Analysis Platform

Automation Comprehensive Experiment | Zhejiang University | 2024 Automation Comprehensive Experiment | Zhejiang University | 2024
ESP32-S3 ESP-IDF ESPHome Home Assistant IoT KiCad Sensor Integration Voice Control

本项目围绕智能家居场景，设计并实现了一个基于 ESP32-S3 的智能联动与数据分析平台。 系统集成温湿度、空气质量、人体红外、烟雾等传感器，并结合 LED 灯、风扇、加热器和蜂鸣器等执行器， 实现环境监测、设备联动、语音控制和远程管理。

This project designed and implemented an ESP32-S3 based smart home intelligent linkage and data analysis platform. The system integrates temperature and humidity sensing, air quality monitoring, PIR motion detection, smoke detection, and multiple actuators such as LEDs, fans, heaters, and buzzers for environmental monitoring, device automation, voice control, and remote management.

  • 使用 ESP32-S3 DevKitC-1 作为核心控制器，完成多传感器与执行器集成。
  • 集成 SHTC3 温湿度传感器、SGP30 空气质量传感器、PIR 红外传感器和烟雾传感器。
  • 使用 VS Code + ESP-IDF 进行底层传感器和 GPIO 执行器调试。
  • 结合 ESPHome 与 Home Assistant 实现设备接入、数据上传、自动化联动和 OTA 远程更新。
  • 使用 ASR-PRO 离线语音识别模块实现本地语音控制功能。
  • 使用 KiCad 完成双层 PCB 原理图设计、布局布线与 Gerber 文件输出。
  • Used ESP32-S3 DevKitC-1 as the core controller for sensor and actuator integration.
  • Integrated SHTC3 temperature and humidity sensor, SGP30 air quality sensor, PIR motion sensor, and smoke sensor.
  • Debugged low-level sensor communication and GPIO actuator control using VS Code and ESP-IDF.
  • Used ESPHome and Home Assistant for device integration, data upload, automation rules, and OTA updates.
  • Implemented local voice control using an ASR-PRO offline voice recognition module.
  • Completed schematic design, double-layer PCB layout, and Gerber output using KiCad.

该项目覆盖传感器调试、执行器控制、Home Assistant 平台接入、语音控制、PCB 设计和硬件打样。

This project covers sensor debugging, actuator control, Home Assistant integration, voice control, PCB design, and hardware prototyping.
