基于视频的人形机器人动作模仿训练系统 Video-based Humanoid Robot Motion Imitation Pipeline

MP4 Video → GVHMR → GMR → RSL-RL / Isaac Lab → Unitree G1
GVHMR GMR RSL-RL Isaac Lab Unitree G1 Imitation Learning

本项目构建了一套从普通人体动作视频到人形机器人模仿训练的完整流程。 首先使用 GVHMR 从 MP4 视频中恢复人体三维运动，再通过 GMR 将人体动作重定向到 Unitree G1 人形机器人模型， 随后将动作数据转换为 RSL-RL / Isaac Lab 可用于训练的数据格式，并进行强化学习模仿训练与策略测试。

This project builds an end-to-end pipeline from ordinary human motion videos to humanoid robot imitation learning. GVHMR is used to recover 3D human motion from MP4 videos, and GMR is then applied to retarget the recovered motion to the Unitree G1 humanoid robot model. The retargeted motion data is converted into formats suitable for RSL-RL / Isaac Lab training.

  • 使用 GVHMR 从单目 MP4 视频中恢复人体全局运动与姿态信息。
  • 使用 GMR 将人体 SMPL / SMPL-X 动作重定向到 Unitree G1 机器人关节空间。
  • 将动作数据转换为机器人模仿学习训练所需的 NPZ / 轨迹数据格式。
  • 基于 RSL-RL / Isaac Lab 进行人形机器人动作模仿训练。
  • Recovered global human motion and pose information from monocular MP4 videos using GVHMR.
  • Retargeted SMPL / SMPL-X human motion to the Unitree G1 robot joint space using GMR.
  • Converted motion data into NPZ / trajectory formats required for robot imitation learning.
  • Trained humanoid motion imitation policies using RSL-RL / Isaac Lab.

本科毕业论文：基于无感 FOC 与 Q-learning PID 优化的电动滚筒调速控制研究 Undergraduate Thesis: Electric Roller Speed Control Based on Sensorless FOC and Q-learning PID Optimization

Ongoing｜预计 2026 年完成 Ongoing | Expected completion in 2026
Electric Roller Sensorless FOC Q-learning PID Optimization VESC Motor Control Logistics Automation

本科毕业论文聚焦于物流自动化场景下电动滚筒的调速控制问题。 针对传统 PID 参数整定依赖经验、难以适应复杂工况的问题，研究基于无位置传感器 FOC 的电机控制方法，并结合 Q-learning 强化学习算法对速度环 PID 参数进行优化。 控制系统基于 Benjamin Vedder Electric Speed Controller（VESC）开源平台搭建， 重点验证算法在目标转速跟踪、稳态误差、动态响应和突加负载扰动下的控制性能。

This undergraduate thesis focuses on speed control for electric rollers in logistics automation systems. To address the limitations of manually tuned PID parameters under varying operating conditions, the project studies a sensorless Field-Oriented Control method and applies Q-learning to optimize the PID parameters of the speed loop. The control system is built on the Benjamin Vedder Electric Speed Controller VESC open-source platform, with evaluation focused on speed tracking, steady-state error, dynamic response, and robustness under sudden load disturbances.

  • 研究无位置传感器 FOC 控制策略，降低系统对位置传感器的依赖。
  • 结合滑模观测器与高频注入方法，实现转子位置与速度估计。
  • 使用 Q-learning 对速度环 PID 参数进行自动优化。
  • 基于 VESC 平台搭建电动滚筒控制实验系统。
  • 实验评价指标包括稳态误差、上升时间、超调、振荡和负载扰动恢复性能。
  • Studied sensorless FOC control to reduce dependence on mechanical position sensors.
  • Combined sliding-mode observer and high-frequency injection methods for rotor position and speed estimation.
  • Applied Q-learning to automatically optimize speed-loop PID parameters.
  • Built an electric roller control test system based on the VESC platform.
  • Evaluated steady-state error, rise time, overshoot, oscillation, and recovery under sudden load disturbance.
