项目经历 Projects

基于视频的人形机器人动作模仿训练系统 Video-based Humanoid Robot Motion Imitation Pipeline

MP4 Video → GVHMR → GMR → RSL-RL / Isaac Lab → Unitree G1
GVHMR GMR RSL-RL Isaac Lab Unitree G1 Imitation Learning

本项目构建了一套从普通人体动作视频到人形机器人模仿训练的完整流程。 首先使用 GVHMR 从 MP4 视频中恢复人体三维运动，再通过 GMR 将人体动作重定向到 Unitree G1 人形机器人模型， 随后将动作数据转换为 RSL-RL / Isaac Lab 可用于训练的数据格式，并进行强化学习模仿训练与策略测试。 项目重点解决人体动作恢复、机器人关节映射、动作数据转换、仿真训练和策略验证之间的工程衔接问题。

This project builds an end-to-end pipeline from ordinary human motion videos to humanoid robot imitation learning. GVHMR is used to recover 3D human motion from MP4 videos, and GMR is then applied to retarget the recovered motion to the Unitree G1 humanoid robot model. The retargeted motion data is converted into formats suitable for RSL-RL / Isaac Lab training, followed by reinforcement learning-based motion imitation and policy evaluation. The project focuses on the engineering connection between human motion recovery, robot joint mapping, motion data conversion, simulation training, and policy testing.

  • 使用 GVHMR 从单目 MP4 视频中恢复人体全局运动与姿态信息。
  • 使用 GMR 将人体 SMPL / SMPL-X 动作重定向到 Unitree G1 机器人关节空间。
  • 将动作数据转换为机器人模仿学习训练所需的 NPZ / 轨迹数据格式。
  • 基于 RSL-RL / Isaac Lab 进行人形机器人动作模仿训练。
  • 完成从视频输入、动作恢复、机器人重定向到仿真策略测试的完整闭环。
  • Recovered global human motion and pose information from monocular MP4 videos using GVHMR.
  • Retargeted SMPL / SMPL-X human motion to the Unitree G1 robot joint space using GMR.
  • Converted motion data into NPZ / trajectory formats required for robot imitation learning.
  • Trained humanoid motion imitation policies using RSL-RL / Isaac Lab.
  • Completed an end-to-end workflow from video input and motion recovery to robot retargeting and policy testing.
